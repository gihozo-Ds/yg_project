# Rasi Prints (React + Chakra UI)

A React + Chakra UI implementation inspired by https://rasiprintsweb.netlify.app/.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import the repository in Vercel.
3. Framework preset: **Vite**.
4. Build command: `npm run build`
5. Output directory: `dist`

The branding favicon is available at `public/favicon.svg`.
